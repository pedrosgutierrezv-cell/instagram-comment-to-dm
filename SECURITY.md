# Reportar vulnerabilidades

No publiques secretos, pruebas con datos de seguidores ni detalles explotables de instalaciones de terceros en issues. Usa **Report a vulnerability** en la pestaña Security de GitHub cuando esté habilitado. Si no está disponible, abre un issue solicitando un canal privado sin incluir la vulnerabilidad.

La versión 0.1.x es la única línea que se evalúa inicialmente. La revisión del laboratorio y las medidas incluidas están en docs/SECURITY.md y docs/SECURITY-REVIEW.md. No se garantiza un plazo de respuesta ni una certificación. Los mantenedores no necesitan tus claves para reproducir un fallo.
